Verified 19 October 2026 on Windows, Node.js 24.13, Next.js 16.4.2, React 19.3.1, and Chromium 156 through Playwright.

## Commands actually run

- `npm install` and dependency installation commands; `package-lock.json` is included.
- `npm run lint` — passes without warnings.
- `npm run typecheck` — passes.
- `npm test` — 39 behavior tests pass.
- `npm run build` — production build passes.
- `npm audit` — zero reported vulnerabilities, including development dependencies.
- `npx playwright install chromium` — browser installed for the test suite.
- `npm run test:e2e` — 19 browser tests pass against the production build using `PLAYWRIGHT_BASE_URL=http://127.0.0.1:3001` and `npm start -- -p 3001`.

## Measured local rendering

The production rendering check uses Chromium at 390 × 844, localhost, without CPU/network throttling. The final run measured LCP **420 ms** and CLS **0.00014**. Raw results are in `artifacts/performance.json`. These are local measurements, not field performance or a claim about mobile networks.

## Scope and verification limits

This is a local interactive demo. No real family data, child authentication, device session, invitation delivery, private server media, scheduler, geolocation, or cross-device service is implemented. Those belong to the PRD's connected deliverable and are explicitly unavailable.

Real browser location permission-denied/unavailable prompts and offline server stop acknowledgements are not simulated as successful remote actions. Actual device keyboard behavior, physical touch, iOS safe-area rendering, screen-reader usability, real network performance, and connected security gates require separate device/integration testing. Automated accessibility checks are not a complete accessibility audit or compliance claim.

Due processing runs on load and every 30 seconds while open; no delivery is promised while the page is closed. Sample coordinates are fictional, shared only inside the local database, and expire without extending their original deadline. The demo has no server retention, backup, or remote-deletion operation to certify.
